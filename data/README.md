# Data Format

This directory contains a CSV template showing the expected format for your dataset.  
The full dataset is not publicly available (patient privacy); see the paper's data availability statement.

---

## CSV format (`csv_template.csv`)

The label CSV uses **semicolon** (`;`) as separator and requires these columns:

| Column | Type | Description |
|--------|------|-------------|
| `id` | int | Unique row index |
| `filename` | str | Sample folder name (must match a subfolder in your `plot_dir`) |
| `binary_class` | int | 0 = Normal / Non-PH, 1 = Pulmonary Hypertension |
| `split` | str | `train`, `val`, or `test` (used for non-CV single-run training) |
| `fold_test` | int | Test fold assignment (0–4) |
| `fold_val` | int | Validation fold assignment (0–4) for the corresponding test fold |

The `fold_test` and `fold_val` columns are generated by `preprocessing/create_nested_folds.py`.

---

## Plot directory structure

Each sample in `filename` must correspond to a subdirectory containing exactly 9 panel PNGs:

```
plot_dir/
├── case_000001/
│   ├── plot_01.png
│   ├── plot_02.png
│   └── ... plot_09.png
├── case_000002/
│   └── ...
```

Panels are produced by `preprocessing/preprocess_plots.py` from raw CPET PDF files.

---

## Sample data

`sample_data/` contains 20 fully anonymized example cases with the same structure,
usable for testing the full inference and training pipeline without access to the full dataset.
